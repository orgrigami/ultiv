Scope: the whole client surface; visitor mode Operate. Audience: one owner operating a crew of persistent AI entities from a dark desk (desktop primary, phone secondary).

## Direction contract

THESIS: the owner's night station for a crew of autonomous entities — an observatory control room, not a chat app: catalogued named objects, instrument-grade calm, and one disciplined signal light; the category-default floating-pill chat shell is refused as the identity, kept only as furniture.

OWN-WORLD: deep blue-black ground with warm-tinted ivory ink, four lightness elevation tiers, hairline rules at one device pixel; Geist Mono as the instrument voice (overlines, readouts, catalog marks, tabular accounting) under Geist Sans prose; bots carry star-catalog spectral tints; a single red-light signal color reserved for what demands the owner (attention, errors), amber only for live work; no glow anywhere.

STORY: the owner reads at a glance who is working, what waits for them, and what anything cost; tool activity rides as a numbered overlay layer above the prose terrain, never mixed into it; every expanded view explains, never dumps.

FIRST VIEWPORT: console rail left (wordmark plate, crew roster with presence marks, labeled systems nav, per-bot recents, owner block with theme control), center the current bot's transcript with the overlay-layer tool trace, floating pill composer; on phones, tab bar with Crew, Routines, centre Chat, Tools, More.

FORM: the assigned grounded direction from the seven-candidate roll (observatory control room); the roll's seed reference stays in the session run record, not in this committed document.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
